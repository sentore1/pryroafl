# Pryro AI Panel - Quick Reference Card

**Quick Start:** Click the "AI" button in the top navigation bar to open the panel.

---

## ⚡ Quick Actions Bar

| Button | What It Does | When to Use |
|--------|--------------|-------------|
| 📊 **System Status** | Full briefing of all operations | Morning check-in, shift start |
| ⚠️ **Stuck Shipments** | Shipments with no updates 24+ hours | Daily monitoring |
| 💰 **Payments** | Pending and overdue payments | Payment processing |
| 🚛 **Drivers** | Driver workload and availability | Assignment planning |
| 📈 **Revenue** | Revenue trends and predictions | Weekly/monthly reviews |

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| **Enter** | Send message |
| **Esc** | Close panel |

---

## ⚙️ Settings Options

### AI Provider
- **Groq** (Default) - Fast & Free
- **OpenAI** - Premium Quality

### Response Length
- **Brief** - Quick answers
- **Normal** - Standard detail
- **Detailed** - Full analysis

### Auto-Refresh
- Off, 30s, 1min, 5min

### Sound
- On/Off

## 🎯 Action Buttons

When AI suggests actions, you'll see colored buttons:

| Color | Type | Examples |
|-------|------|----------|
| 🔵 Blue | General | Assign driver, update info |
| 🟢 Green | Payments | Confirm payment, approve transfer |
| 🟠 Orange | Status | Mark in transit, update status |
| 🔷 Teal | Assignments | Assign driver, change route |

**Click any button to execute the action instantly.**

## 📊 What AI Can Do

### ✅ AI Can:
- View all shipments, drivers, payments
- Confirm payments
- Update shipment status
- Assign drivers
- Analyze revenue trends
- Generate system briefings
- Answer operational questions

### ❌ AI Cannot (Yet):
- Create new shipments
- Send SMS/WhatsApp/Email
- Generate reports (PDF/Excel)
- Delete records
- Change prices
- Create users

## 💡 Pro Tips

1. **Use Quick Actions** - Faster than typing
2. **Be Specific** - Include tracking numbers or names
3. **One Question at a Time** - Better accuracy
4. **Save Settings** - Customize for your workflow
5. **Enable Sound** - Know when AI responds
6. **Try Fullscreen** - Better for deep analysis
7. **Auto-Refresh** - Real-time monitoring

---

## 🐛 Quick Troubleshooting

**AI not responding?**
→ Check API key in Tools → AI Settings

**Enter key not working?**
→ Hard refresh (Ctrl + Shift + R)

**Settings not saving?**
→ Exit private browsing mode

**No sound?**
→ Enable in Settings panel
