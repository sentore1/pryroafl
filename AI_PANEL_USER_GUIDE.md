## ⚙️ Settings (Customize AI Behavior)

Click the **⚙️ Settings** button in the header to configure:

### AI Provider
**Groq (Fast & Free)** ⭐ Recommended
- Lightning fast responses (1-2 seconds)
- Free unlimited usage
- Uses Llama 3.3 70B model
- Best for daily operations

**OpenAI (GPT-4o)** 💎 Premium
- Higher quality analysis
- Better understanding of complex questions
- Costs money per query
- Best for important decisions

### Response Length
**Brief** ⚡
- Short, to-the-point answers
- 50-100 words
- Fastest responses
- Best for quick checks

**Normal** ⭐ Recommended
- Balanced detail
- 100-200 words
- Standard responses
- Best for most questions

**Detailed** 📝
- Comprehensive analysis
- 200-400 words
- In-depth explanations
- Best for complex issues

### Auto-Refresh Briefing
**Disabled** ⭐ Default
- Manual refresh only
- You control when to update
- Best for on-demand use

**Every 30 seconds** 🔄
- Real-time monitoring
- Constant updates
- Best for control center use
- High API usage

**Every minute** 🔄
- Frequent updates
- Balanced monitoring
- Moderate API usage

**Every 5 minutes** 🔄
- Periodic check-ins
- Low API usage
- Good for background monitoring

### Sound Notifications
**Enabled** 🔊 Default
- Plays sound when AI responds
- Plays sound when actions complete
- Helps when multitasking

**Disabled** 🔇
- Silent operation
- No audio notifications
- Best for quiet environments

**Don't forget to click "Save Settings"** after making changes!

## 🆘 Troubleshooting

### AI Panel Won't Open
**Solution:**
- Hard refresh page (Ctrl + Shift + R)
- Clear browser cache
- Check if you're logged in as admin

### Enter Key Not Working
**Solution:**
- Click the send button (blue arrow) instead
- Try Tab then Enter
- Hard refresh page

### AI Not Responding
**Solution:**
- Wait 10 seconds (might be slow connection)
- Check internet connection
- Go to Tools → AI Settings → Verify API key
- Try switching provider (Groq ↔ OpenAI)

### Settings Not Saving
**Solution:**
- Exit private/incognito mode
- Enable browser cookies
- Check browser localStorage settings

### ACTIONS_JSON Visible in Chat
**Solution:**
- This was a bug, now fixed
- Hard refresh page (Ctrl + Shift + R)
- Should no longer appear

### Action Buttons Not Working
**Solution:**
- Wait 5 seconds and try again
- Check shipment still exists
- Verify you have permissions
- Contact system administrator
